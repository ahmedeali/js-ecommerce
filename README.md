# JS E-Commerce Platform

A full-stack JavaScript-based e-commerce web application designed to allow customers to browse products and purchase them online, while enabling administrators to manage products and orders.

---

## Project Overview

This project is a learning-focused but production-oriented implementation of a modern e-commerce system.  
It follows a structured, phase-based development approach similar to real-world software projects.

---

## Objectives

- Build a complete full-stack web application using JavaScript
- Apply software engineering best practices
- Develop a scalable and maintainable codebase
- Deploy a real, usable application to production

---

## Target Users

### Customers
- Browse products
- View product details
- Add products to cart
- Place orders online

### Admin (Store Owner)
- Manage products (add, edit, delete)
- View customer orders
- Update order status

---

## Scope (Version 1 – MVP)

### In Scope
- User authentication
- Product catalog
- Shopping cart
- Order placement
- Admin product and order management
- Online payment integration

### Out of Scope
- Mobile applications
- Product reviews and ratings
- Discounts and coupons
- Multi-vendor support
- Advanced analytics

---
